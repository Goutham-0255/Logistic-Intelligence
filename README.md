# 📦 Logistic Intelligence

**Logistic Intelligence** is an automated pipeline designed to process, extract, and analyze information from logistical documents such as invoices and receipts. Leveraging specialized modules for image preprocessing, text extraction, and intelligent parsing, this tool streamlines data entry and document management workflows.

---

## 📂 Project Structure

Here is the detailed, comprehensive layout of the repository and the purpose of each component:

```text
Logistic-Intelligence/
├── .gitignore                 # Specifies intentionally untracked files to ignore (e.g., .env, pycache)
├── docker-compose.yaml        # Docker Compose configuration for simplified container deployment
├── Dockerfile                 # Instructions to build the standalone Docker image for the app
├── requirements.txt           # Python dependencies (OpenCV, EasyOCR, Gemini, Streamlit, etc.)
├── app.py                     # Main Streamlit web application interface for UI interaction
├── main.py                    # Command-Line Interface (CLI) entry point for the pipeline
├── data/                      # Directory containing all input and output data
│   ├── raw/                   # Unprocessed, original documents ready for extraction
│   │   └── test_invoice.jpg   # Sample invoice image provided for testing the pipeline
│   └── processed/             # Cleaned, deskewed, and binarized images generated by the system
└── src/                       # Core source code and pipeline modules
    ├── brain.py               # Intelligence module leveraging Google Gemini AI for JSON structuring
    ├── extractor.py           # OCR extraction module utilizing EasyOCR to read text from images
    └── preprocess.py          # Computer Vision module (OpenCV) for image deskewing and cleanup
```

## 🚀 Getting Started

You can run this application either locally using a standard Python environment or via Docker.

### Prerequisites

* **Python 3.11+** (If running locally)
* **Docker & Docker Compose** (If running via containers)
* **Google Gemini API Key**

### Option 1: Local Installation

1. **Clone the repository and navigate to the project directory:**
```bash
cd Logistic-Intelligence

```


2. **Create and activate a virtual environment (Recommended):**
```bash
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate

```


3. **Install the dependencies:**
```bash
pip install -r requirements.txt

```


4. **Set up Environment Variables:**
Create a `.env` file in the root directory and add your API key:
```env
GEMINI_API_KEY=your_gemini_api_key_here

```


5. **Run the application:**
Depending on your workflow, you can start the web app or the CLI tool:
```bash
# To launch the Streamlit Web UI:
python -m streamlit run app.py

# OR to run the terminal pipeline:
python main.py

```



### Option 2: Docker Deployment

To avoid local environment conflicts, deploy the application using Docker Compose.

1. **Create your environment file:**
Make sure you have a `.env` file in the root directory with your `GEMINI_API_KEY`.
2. **Build and start the container:**
```bash
docker-compose up --build

```


3. **Access the application:**
Open your web browser and navigate to `http://localhost:8501`.

## 🛠️ Usage Pipeline

1. **Input:** Place your logistical documents (e.g., invoices, delivery notes) in the `data/raw/` directory, or upload them directly via the Streamlit UI.
2. **Preprocessing (`src/preprocess.py`):** The system automatically cleans, rescales, and deskews the images to ensure optimal text readability.
3. **Extraction (`src/extractor.py`):** EasyOCR scans the processed image, extracting raw text and bounding box coordinates.
4. **Intelligence (`src/brain.py`):** The Gemini LLM parses the raw text and converts the chaotic data into a cleanly structured JSON format containing the Shipper, Carrier, BOL Number, and itemized lists.
